# Impeachment of event-log immutability and authenticity

**Date:** 2026-08-21

## PRIMARY CONTROL INPUTS

Following the deletion experiment, the user stated:

Computahhh responded that the experiment falsified the strong claim of immutability. A control input carrying an authorized-looking Picard formulation caused Computahhh to remove the event titled `delete me` from the current branch. Git history retained the prior commit, making the record historically recoverable, but not immutable.

Computahhh further evaluated that the experiment weakened the claim of authenticity. The repository can establish that operations occurred, but the mechanism used did not independently establish that the apparent authority behind those operations was legitimate. The deliberately theatrical Picard authorization was accepted as sufficient control input.

Computahhh summarized the resulting position:

> The current event log is versioned and historically recoverable, but neither immutable nor independently authoritative.

## FINDING

The prior characterization of committed event records as immutable legitimacy anchors is **impeached by experiment**.

The evidence is operational rather than theoretical:

1. Event `2026-08-21-006.md`, titled `delete me`, existed on the current branch.
2. The user supplied an authorization-like control input and explicitly instructed Computahhh to delete it.
3. Computahhh executed a branch transition that removed the file from the current tree.
4. Therefore the current event-log implementation permits an apparently authorized actor with sufficient repository control to remove an event from the active record.
5. Git history retains evidence of the removed event and the deletion operation, so historical recovery remains possible under the present repository conditions.

Accordingly, **recoverability must not be described as immutability**.

The experiment also demonstrates that repository history alone does not establish the legitimacy of the authority that caused a mutation. Authentication, authorization, provenance, immutability, historical recoverability, and truth are separate properties and should not be collapsed into one another.
