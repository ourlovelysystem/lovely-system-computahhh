## Additional findings surfaced during the run

### Teambuilder did not participate

Teambuilder did not display the self-destruct banner and did not disappear when the system went offline.

Inspection established that its entry pages did not load the shared lifecycle alert script. Event 091 preserved this failure before repair. The script was subsequently added to the main Teambuilder page, Yellow Lion, Shooting Gallery, and Shooting Gallery Witness.

That repair occurred during the active test and cannot retroactively convert the observed integration failure into a pass.

### Disappearance overlay did not cover the viewport

The progress application displayed “Not Found,” but the white replacement surface ended before the right edge and exposed the underlying progress page.

The cause was a host-page CSS collision:

```css
main {
  width: min(94vw, 900px);
}
```

The shared disappearance element was also a `<main>` and did not explicitly reset the inherited width. Host typography also centered the “Not Found” heading.

The shared overlay was subsequently isolated from host width, height, margin, transform, box-sizing, and heading-alignment rules.

That repair also occurred during the test and cannot retroactively make the original presentation correct.
