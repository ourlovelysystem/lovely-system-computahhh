# Event 191 — Pledge state-record contract and interrupted-publication correction

## State-record minimum

The production state table is `lovely-system-pledge-state`. Its partition key is `parameter_name`.

```json
{
  "parameter_name": "run_mode",
  "parameter_value": "ready"
}
```

Both fields are required. `parameter_name` selects the state record; `parameter_value` holds that parameter's value.

`updated_at` is not a DynamoDB system attribute and is not part of the required minimum. The completion Lambda writes it when it changes `run_mode`; a manual console edit does not. It is optional automation metadata.

## Recognized parameters

| Parameter | Valid recognized values | Effect | Default for absent, empty, unknown, or wrong-type values |
| --- | --- | --- | --- |
| `run_mode` (String) | `ready` | Blank dark page displaying only “Ready.” | Diagnostic page. `standby` is not specially recognized. |
|  | `voiceless` | Voice-lending page. |  |
| `save_transcript_to_object` (Boolean) | `true` | Completion Lambda loads `transcripts/<receipt>.json` from S3. | Uses the Amazon Transcribe URI. |
| `save_transcript_to_database` (Boolean) | `true` | Stores `transcript_text` in the catalog record. | Removes/does not retain `transcript_text`. |

Manual state probes established that `ready` renders Ready, `voiceless` renders the lending page, and `standby`, empty, and `yabba dabba doo` render the diagnostic response view.

The previously observed initial standby-view flash is recorded as an observation only. No correction was made.
