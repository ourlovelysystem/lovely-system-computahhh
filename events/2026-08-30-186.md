## ACCEPTED RULE

A completed recording that receives final `content_decision = usable` and `catalog_eligible = true` causes Pledge to set `run_mode = ready` unless it is already ready.

## IMPLEMENTATION

The transcription-completion Lambda was updated and deployed as Lambda version `3`.

The first test exposed a missing, narrow permission: the Lambda role could read but not update the state table. An inline role policy granting only `dynamodb:UpdateItem` on `lovely-system-pledge-state` was added. No broad DynamoDB permission was added.

## VERIFIED RESULT

The completed receipt `1c37a153-2f6c-44fc-93f8-bec76e2e01e9` was manually rerun.

- Lambda invocation: HTTP 200; no function error.
- Semantic evaluation: `evaluated`; score `1.0`; candidate `usable`.
- State-table read: `run_mode = ready`.

The transition is now live.
