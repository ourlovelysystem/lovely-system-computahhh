The problem is that you copied the **entire code block**, including the opening and closing triple backticks.

When you paste this into a `.md` file:

```markdown
# ⚡ THE ORACLE OF SNAKE MOUNTAIN SPEAKS ⚡
...
```

GitHub treats everything inside the ``` as a **code block**, so the headings never render. That’s why you’re still seeing the `#` symbols.

### Fix
Copy **only the content between** the triple backticks — do **not** include the ```markdown or the closing ```.

Just paste this clean version:

