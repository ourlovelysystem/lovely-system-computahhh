## WHAT WAS ACTUALLY TESTED

Rather than answer from memory, Claude attempted direct access. Fetching `arweave.net/graphql` returned only the GraphQL Playground's loading shell, not query results — because the endpoint requires a POST request with a query body, and the available fetch tool only sends GET. Fetching `viewblock.io/arweave` did return live, real data: current network statistics (24.7 billion total transactions, 0.61 TPS, 314,026 addresses, 12.24 AR/GiB storage cost) and a browsable feed of recent transactions and blocks.

Searching for the specific Ukraine-related Arweave archive referenced in 2022 press coverage (Bloomberg, Forbes — reportedly ~6.5 million items, ~50TB, uploaded directly to Arweave during the invasion) surfaced `ukrainewararchive.org`. Direct inspection of that site found no mention of Arweave, blockchain, or decentralized storage — it is a separate project (Docudays UA and Infoscope, EU-supported), not the same initiative as the Arweave-based archive. This was checked and flagged rather than assumed, given Event 219's finding on this same day.

**Conclusion on access:** browsing a live Arweave explorer through a GET-based fetch works. Structured search across the archive by tag, owner, or content category does not, with the tools available — that requires the GraphQL endpoint's POST interface.

## ARWEAVE'S QUERY MODEL, AS DOCUMENTED

Two decoupled layers:

1. **Metadata search via GraphQL**, run by gateways (arweave.net, ar.io, others) indexing the underlying chain — the base protocol itself has no native query capability. Filterable by transaction `id`, `owner`/`recipient` address, `tags` (arbitrary name/value pairs set at upload — the primary categorization mechanism, since Arweave has no native folder structure), and block height range, sortable by height. Pagination uses a cursor model (`first`, `after`).
2. **Content retrieval, separately.** GraphQL returns only metadata — tags, fees, timestamps, addresses. Actual file content requires a second step: fetching by transaction ID via direct HTTP GET (`arweave.net/{id}`) or an SDK call such as arweave-js's `getData()`.

A third layer, ANS-104 bundling, packs many small uploads into one wrapping transaction for cost efficiency (how services like ArDrive operate); gateways index bundled items with a `bundledIn` field tracing each one back to its parent, recursively for nested bundles.
