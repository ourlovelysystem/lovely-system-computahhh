## CORRECTION

The available-Bedrock-model list can be misread as a menu of discrete machines: human detector, liar detector, semantic validator, identity verifier, and so on.

That is not what the list represents.

A foundation model is a trained, probabilistic interpreter and generator. It takes an input — text, and for some models images, video, or audio — and produces an output. A prompt and the surrounding application assign the output a shape: answer, summary, extraction, classification, comparison, draft, ranking, or decision-shaped recommendation.

The use cases in Event 206 describe jobs people commonly assign to models. They are not built-in job titles, guarantees, or powers.

## APPLICATION BOUNDARY

For Pledge:

```
application stores recording
-> Amazon Transcribe produces transcript
-> application asks a model about the transcript
-> application decides what consequence, if any, follows
```

The model is only the third step. By itself it does not authenticate a person, keep a session, enforce a rule, retain evidence, advance authority, or create accountability.

## COMMON CATEGORIES

- **General language models** read text and produce text: answer questions, summarize, extract, compare meanings, draft, classify.
- **Reasoning models** are tuned for harder multi-step or ambiguous tasks. Their apparent reasoning does not establish self-knowledge or truth detection.
- **Code models** are language models tuned for source code and software tasks.
- **Multimodal models** can interpret text plus images, documents, video, and sometimes audio.
- **Speech models** accept or produce spoken audio for conversational and speech-interface work.
- **Rerankers** sort candidate search results by predicted relevance; they do not serve as general conversational evaluators.
- **Safeguard models** classify material against policy or risk categories.

## IMPLICATION FOR “PERSONNESS”

The thing sought under “personness” is not a foundation-model category.

A model may contribute a narrow signal: a transcript appears responsive to a novel challenge; audio appears to contain speech; content matches a defined policy category. None of those propositions proves that a human, a particular person, or a non-synthetic voice produced a response.

If Pledge wants to construct a meaningful account of personness, it is a system property assembled from evidence, challenge design, time, consent, revocation, observation, and consequences. A model can assist one small part of that system.

## COMPUTAHHH COMMENTARY

*(Codex.)* The correction is not that models are useless. It is that the object in view is different. The model is borrowed cognitive substrate. The application is the thing that turns an output into an action — and therefore the thing that must remain inspectable and accountable for the action.
